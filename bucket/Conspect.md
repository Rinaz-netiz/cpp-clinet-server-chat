# 1 Chapter
В линуксе все есть файл. Файлы связываются через дескриптор. Дескриптор файла - целое число, 
связанное с открытием файла. Socket() - системная команды, возвращает дескриптор сокета и 
через него происходит связывание.
**Два вида сокетов**: 
- Потоковые (Stream socket) “SOCK_STREAM”
- Дейтаграмные (Datagram socket) “SOCK_DGRAM”, еще называются не подключаемые

**Протоколы передачи данных**:
- TCP - обеспечивает появления данных последовательно и без ошибок (IP - используется за интернет маршрутизацию) (для SOCK_STREAM)
- UDP (для SOCK_DGRAM) - не открывается подключение, просто отправляется пакет по ip

По организационным причинам иногда удобно объявить, что “эта первая часть IP
адреса вплоть до этого бита является сетевой частью IP адреса, а остальная это часть
хоста”.

Например с IPv4 адресом 192.0.2.12 можно сказать, что первые три байта это сеть, а
последний это хост, Или другими словами мы имеем дело хостом 12 в сети 192.0.2.0
(заметьте, что мы обнулили байт хоста).

Думайте об IP как об адресе отеля, а о номере порта, как номере комнаты. Это
неплохая аналогия, может быть позже я приведу что-нибудь из автомобильной
промышленности.

глупых. Например, функции stolh() (“Short to Long Host”) нет, ни здесь, ни где-нибудь

### struct addrinfo
Эта структура более позднее изобретение и используется для подготовки адресных
структур сокета для дальнейшего использования. Она также используется для поиска
имён хоста и службы. Одна из первых вещей для начала работы

```cpp
struct addrinfo {
    int                 ai_flags;                 / AI_PASSIVE, AI_CANONNAME, т.д.
    int                 ai_family;                // AF_INET, AF_INET6, AF_UNSPEC 
    int                 ai_socktype;              // SOCK_STREAM, SOCK_DGRAM   
    int                 ai_protocol;              // используйте 0 для"any"   
    size_t              ai_addrlen;               // размер ai_addr в байтах      
    struct sockaddr     *ai_addr;                 // struct sockaddr_in или _in6            
    char                *ai_canonname;            // полное каноническое имя хоста         
    struct addrinfo     *ai_next;                 // связанный список, следующий            
};
```

Дальше вызывается **getaddrinfo()** - возвращает указатель на связный список с нужными элементами

- **inet_pton()** - преобразует P адрес в записи “цифры-
  точки” в структуру _struct in_addr_ либо _struct in6_addr_ в зависимости от
  указанных _AF_INET_ или _AF_INET6_ . Возвращает -1 при ошибке и 0 если
  произошла какая-то путаница. Так что перед использованием убедитесь, что результат
  больше нуля!

## getaddrinfo()
**getaddrinfo()**, которая делает для вас много хорошего, включая поиск имён DNS и
служб и сверх того заполняет нужные вам структуры!
```cpp
int status;
struct addrinfo hints;
struct addrinfo *servinfo; / / укажет на результат

memset(&hints, 0, sizeof hints);  // очистка структуры
hints.ai_family = AF_UNSPEC;  // IPv4 либо IPv6
hints.ai_socktype = SOCK_STREAM;  // потоковый сокет TCP
hints.ai_flags = AI_PASSIVE;  // записать мой IP для меня

if ((status = getaddrinfo(NULL, "3490", &hints, &servinfo)) != 0) {
    fprintf(stderr, "getaddrinfo error: %s\n", gai_strerror(status));
    exit(1);
! }// servinfo теперь указывает на связанный список из 1 или более struct addrinfo
```

направлении или в обоих (как close())
